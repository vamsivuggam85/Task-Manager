
# Task Manager Web Application

## About the Project
A responsive Task Manager web application developed using HTML, CSS, and JavaScript. It helps users organize tasks and track their progress through a simple interface.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks by title
- Filter tasks by status and category
- Set task categories and due dates
- View task statistics
- Save tasks in browser localStorage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Alternatively, use the Live Server extension in VS Code.

## Project Structure
- `index.html` - Page structure
- `style.css` - Styling and responsive layout
- `script.js` - Task management functionality
